# Financial-Planner
A simple expense tracker for daily use.

## Stack
- currently using basic html, css and js
- ide: vscodium

## Features
- dynamic input where you can add expense type and amout
- the information will be saved in transaction history
- using monospace font and white background for clean and minimal design

## How to run it locally on your device
``` git clone https://github.com/Jas-source-tech/Financial-Planner.git ```
